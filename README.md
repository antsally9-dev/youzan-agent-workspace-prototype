# 有赞商家经营 Agent Workspace · 交互原型

> 个人独立研究 · 基于公开资料的方向性构想 · 页面为设计原型，示例业务数据、操作与 Agent 回复均不会连接真实店铺。

在线预览：**https://antsally9-dev.github.io/youzan-agent-workspace-prototype/**

## 这是什么

一份「商家经营 Agent Workspace」的高保真交互原型（纯 HTML/CSS/JS 单文件，无后端、无真实数据），用于产品构想的演示与讨论。

- 以 **Task** 为核心工作对象：目标、对话、业务数据引用、待确认动作与产物在同一上下文中
- 一周工作台首页：昨日进展、今日待决、值得关注
- 经营日历、洞察与观察、资产目录、经营档案（长期事项跨日期关联）
- 内嵌业务页示例：客户与会员 / 商品与库存 / 订单与履约 / 营销与内容 / 门店与渠道 / 财务与经营数据
- 桌面端与移动端（≤650px 底部导航布局）均已适配；可在手机浏览器直接打开

## 角色

顶栏可切换演示角色：店主 / 总部 / 店员，不同角色看到不同的范围与动作。

## 说明

- 页面内所有数据均为演示数据（标注"演示"字样）
- 本原型为独立研究产物，与有赞官方产品无关
